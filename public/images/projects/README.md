# Proje Ekran Görüntüleri

Uygulama içi ekran görüntülerini bu klasöre koyun.

## Kullanım

1. Görseli bu klasöre ekleyin — tercihen 16:9 oranında, `.png` veya `.webp` (örn: `myzoo.png`)
2. Supabase Dashboard → Table Editor → `projects` tablosunda ilgili projenin
   `image_url` alanını `/images/projects/myzoo.png` olarak güncelleyin
3. Değişiklik anında yayına yansır (görsel siteyle birlikte deploy edilir)

## Öneriler

- Kartlarda görsel 16:9 (`aspect-video`) kırpılır; ekran görüntüsünü buna göre alın
- Dosya boyutunu ~300 KB altında tutun (gerekirse https://squoosh.app ile sıkıştırın)
- Dosya adları küçük harf ve tire ile: `pneumonia-detection.png`
